Install, organise and manage your Maschine libraries from one native Mac app.

macOS 14 or later · Apple Silicon and Intel

Maschinery takes the repetitive work out of managing Maschine expansions. Install several libraries at once, fix broken content paths, move libraries to another drive, and browse the expansions missing from your collection.

## Features

* Bulk installation: Drop in ISOs, PKGs or library folders, review the detected libraries and artwork, then choose where to install them.
* Control over existing libraries: Merge files, replace a library, skip it or choose another location. Reinstall directly from the installation queue.
* Library management: Check installed libraries for problems, repair read permissions, locate missing content and replace registration XML.
* Move and uninstall: Relocate libraries with file verification and updated registration, or remove their registration with the option to keep the content or move it to Trash.
* Expansion catalogue: Browse official Maschine expansions with artwork, search, Installed/Missing filters and collection statistics. Missing means a library wasn’t detected locally, regardless of ownership.
* Extract only: Unpack supported installers without registering a library.
* Offline support: Use your own product XML files and browse the bundled catalogue without an internet connection.
* Useful diagnostics: View progress and logs, retry failed installations and export a results report.

Maschinery verifies copied files before completing an installation or move. Source files are kept by default; optional cleanup uses the Mac’s reversible Trash. Interrupted operations retain recovery information so they can be resolved when you reopen the app.

## Installation

1. Download the installation .PKG file from this repository’s [Releases page](https://github.com/BarsOfProgress/Maschinery/releases).
2. Open the package and follow the installer’s instructions. Administrator approval is required.
3. Launch Maschinery from Applications.

The full installer includes the background component needed to install and maintain library registrations.

The installer is unsigned and isn’t notarised by Apple. If macOS blocks it, attempt to open it, then go to System Settings → Privacy & Security → Open Anyway.

## Getting started

Drop your library files into Maschinery, review the queue, choose your destination and press Install. Use Extract Only if you just want to unpack the files.

Open Libraries to browse your collection, check for issues, move content or uninstall a library.
